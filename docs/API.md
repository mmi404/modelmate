# ModelMate — REST API

Base path: **`/api/v1`**. JSON in/out. Auth via `Authorization: Bearer <jwt>`
(attached by the Next.js server from the session cookie).

The live, authoritative spec is generated by springdoc at
`/api/v1/openapi.json` (Swagger UI `/api/v1/docs` in dev/staging). This document
is the design target.

## Conventions

- **Pagination:** `?page=0&size=20&sort=field,dir`. Responses:
  `{ content: [...], page, size, totalElements, totalPages }`.
- **Errors:** `{ timestamp, status, error, message, path, fieldErrors?: {field: msg} }`.
- **Auth levels:** 🔓 public · 🔒 authenticated · 🛡️ admin.
- Public list/detail endpoints only return `APPROVED` models and `VISIBLE` content.
- Timestamps ISO-8601 UTC.

## Auth — `/auth`

| Method | Path | Lvl | Body | Returns |
|---|---|---|---|---|
| POST | `/auth/register` | 🔓 | `{firstName,lastName,email,password}` | `{token, user}` |
| POST | `/auth/login` | 🔓 | `{email,password}` | `{token, user}` |
| POST | `/auth/logout` | 🔒 | — | `204` (stateless; client drops token) |
| GET  | `/auth/me` | 🔒 | — | `user` |
| POST | `/auth/forgot-password` | 🔓 | `{email}` | `204` (always, no user enumeration) |
| POST | `/auth/verify-reset-code` | 🔓 | `{email,code}` | `{resetTicket}` |
| POST | `/auth/reset-password` | 🔓 | `{resetTicket,newPassword}` | `204` |

Rate limited: register/login/forgot-password — 5 / 15 min / IP.
Optional Cloudflare Turnstile token accepted as `{captchaToken}` when enabled.

`user` = `{ id, firstName, lastName, email, role, avatarUrl, bio, createdAt }`.

## Categories — `/categories`

| Method | Path | Lvl | Notes |
|---|---|---|---|
| GET | `/categories` | 🔓 | list, each with computed `modelCount` |
| GET | `/categories/{slug}` | 🔓 | one category |
| GET | `/categories/{slug}/models` | 🔓 | paginated approved models in category; `?sort=rating,desc\|newest\|name` |

`category` = `{ id, name, slug, description, applications[], modelCount }`.

## Models — `/models`

| Method | Path | Lvl | Notes |
|---|---|---|---|
| GET | `/models` | 🔓 | paginated; filters `?category={slug}&q=&sort=rating\|newest\|reviews` |
| GET | `/models/trending` | 🔓 | top N by recent review volume |
| GET | `/models/search?q=` | 🔓 | typeahead, returns `[{id,name,slug,creator}]` |
| GET | `/models/names` | 🔓 | all approved `[{id,name,slug}]` for compare/review dropdowns |
| GET | `/models/compare?slugs=a,b` | 🔓 | 2–3 models with full rating breakdown side by side |
| GET | `/models/{slug}` | 🔓 | full detail: model + category + submitter + aggregate ratings (overall + 5 dims) + counts |
| POST | `/models` | 🔒 | submit new model → creates `PENDING`; body `{name,creator?,categoryId,description?,websiteUrl}` |

`modelDetail` = `{ id, name, slug, creator, description, websiteUrl, logoUrl,
category:{slug,name}, submitter:{id,name}, createdAt,
ratings:{ overall, accuracy, speed, cost, easeOfUse, reliability, reviewCount },
problemCount }`.

## Reviews & Problems — `/models/{id}/reviews`, `/reviews`

| Method | Path | Lvl | Notes |
|---|---|---|---|
| GET | `/models/{id}/reviews` | 🔓 | paginated `type=REVIEW`, newest/top |
| GET | `/models/{id}/problems` | 🔓 | paginated `type=PROBLEM`, grouped by severity |
| POST | `/models/{id}/reviews` | 🔒 | `{type, title?, content, ratings?:{accuracy,speed,cost,easeOfUse,reliability}, severity?}` — `ratings` required when `type=REVIEW` |
| PUT | `/reviews/{id}` | 🔒 | author only |
| DELETE | `/reviews/{id}` | 🔒 | author or admin |

`review` = `{ id, type, title, content, ratings, overallRating, severity,
reviewer:{id,name,avatarUrl}, upvoteCount, downvoteCount, myVote, createdAt }`.

## Discussions — `/discussions`

| Method | Path | Lvl | Notes |
|---|---|---|---|
| GET | `/discussions` | 🔓 | paginated; `?tags=a,b&sort=newest\|top\|active` |
| GET | `/discussions/tags` | 🔓 | distinct tags with counts (tag cloud) |
| GET | `/discussions/stats` | 🔓 | `{ activeMembers, totalDiscussions, totalReplies }` |
| GET | `/discussions/{id}` | 🔓 | discussion + author |
| POST | `/discussions` | 🔒 | `{title, content, tags[]}` |
| GET | `/discussions/{id}/replies` | 🔓 | threaded replies (one level) |
| POST | `/discussions/{id}/replies` | 🔒 | `{content, parentReplyId?}` |

`discussion` = `{ id, title, content, tags[], author:{id,name,avatarUrl},
replyCount, upvoteCount, downvoteCount, myVote, createdAt }`.

## Votes — `/votes`

| Method | Path | Lvl | Body |
|---|---|---|---|
| PUT | `/votes` | 🔒 | `{targetType:'DISCUSSION'\|'REPLY'\|'REVIEW', targetId, value:1\|-1}` — upsert |
| DELETE | `/votes` | 🔒 | `{targetType, targetId}` — remove vote |

Returns the updated `{ upvoteCount, downvoteCount, myVote }` for the target.
Rate limited: 30 / min / user.
